# Agent Guidelines

- Read `README.md` for project context and contribution conventions.
- Run `mise run build` before completing any task that modifies Swift source files. This ensures formatting and linting pass.
- Run `mise fmt` after modifying `mise.toml`.
- Commit trailers must follow this order and format:
  - `Assisted-by: Mistral-Vibe:MODEL_VERSION` — AI attribution.
  - `Co-Authored-By: Mistral Vibe <vibe@mistral.ai>` — co-authorship credit.
  - `Signed-off-by:` — DCO, only added by humans.
- Do **not** add lines like "Generated by Mistral Vibe" or any other non-standard text in commit messages.
- Use `git commit -F -` with a quoted heredoc when the message contains backticks.
- **Testing style: integration-first.** Tests must exercise types and components working together in realistic workflows (e.g. full turn accumulation, streaming with cancellation, error propagation through pipelines). Do not write per-type construction/equality/switching tests — that only tests the compiler. Each test should cover a meaningful data-flow path through multiple types.
